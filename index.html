SIGNAL FILTER ATLAS

訊號濾波互動圖鑑

一種濾波器一頁。不用先背公式，拉動參數、看波形怎麼變，再回頭理解原理。 所有範例都用同一段合成的步態角速度訊號（fs = 100 Hz），方便橫向比較。

每一頁都長這樣

所有濾波器頁面使用同一套結構，讀完一頁就知道其他頁的東西在哪裡：

#區塊你會得到什麼
1互動 demo拉參數，即時看波形、誤差（RMSE）、延遲與頻率響應
2原理先白話、再公式
3參數怎麼調每個參數調大會怎樣、建議起始值
4優點與限制什麼時候該用、什麼時候不該用
5步態訊號中的應用IMU / 步態分析的實際使用情境
6Python 實作可直接複製執行的 NumPy / SciPy 程式碼
7延伸閱讀官方文件與教科書章節

這個網站是怎麼「長」出來的

本站的規則寫在 repository 裡的 CLAUDE.md。AI 讀完它就知道要怎麼新增下一個濾波器：

  1. 在 assets/js/filters.js 寫演算法（固定的函式簽名）
  2. 在 assets/js/registry.js 註冊頁面 → 首頁卡片、導覽列、上一頁/下一頁自動出現
  3. 複製 templates/filter-page.html，依固定的 7 個區塊填內容
  4. 執行 node scripts/check.mjs 自動檢查是否符合規則

在 Claude Code 裡只要輸入 /new-filter Savitzky-Golay 濾波 就會照這個流程跑一遍。
