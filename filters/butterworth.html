Butterworth 低通濾波Butterworth Low-pass

直接指定「幾 Hz 以下保留、以上去掉」，通帶內的增益盡可能平坦。

原理

前兩頁的濾波器是先想「怎麼算」，再去看它對頻率做了什麼。Butterworth 反過來：先決定想要的頻率響應，再推出計算方式。它的設計目標是讓通帶內的增益「最平坦」（maximally flat），不起伏。

|H(f)|² = 1 / ( 1 + (f / fc)^(2N) )

fc 是截止頻率，此處增益為 1/√2 ≈ 0.707（−3 dB）；N 是階數，超過 fc 後每增加 10 倍頻率，衰減 20·N dB。N 越大，過渡帶越陡，越接近理想的「一刀切」。

實作方式

本站以 N/2 個二階節（biquad）串接，第 k 節的品質因子 Q_k = 1 / (2·sin((2k−1)π / 2N))，搭配雙線性轉換（bilinear transform）與預扭曲，結果與 scipy.signal.butter 相同。

零相位濾波（filtfilt）

單向濾波會讓訊號延遲。filtfilt 先正向濾一次、再把訊號反過來濾一次，兩次延遲剛好抵消。代價是：增益被平方，所以在 fc 處變成 0.5（−6 dB），等效階數也變成 2N。

常見誤區：論文寫「4th-order zero-lag Butterworth, 6 Hz」時，實際在 6 Hz 的衰減是 −6 dB 而不是 −3 dB。要精確對齊 −3 dB 點，需要依 Winter（2009）的方法修正截止頻率。

參數怎麼調

參數意義調大會怎樣建議起始值
截止頻率 fc保留 / 去除的分界頻率保留更多細節，但雜訊也保留更多先看訊號頻譜；步態運動學常用 6 Hz，IMU 角速度常用 5～20 Hz
階數 N過渡帶的陡峭程度切得更乾淨，但延遲與振鈴（ringing）增加2 或 4 階；用 filtfilt 時通常 2 階就等效 4 階
零相位是否使用 filtfilt—離線分析一律用；即時系統不能用

優點與限制

👍 優點

  • 參數有明確物理意義：直接用 Hz 描述要保留什麼
  • 通帶平坦，不會讓某些頻率被放大或扭曲
  • 搭配 filtfilt 可以完全沒有相位延遲
  • 是生物力學文獻的標準做法，方便與他人結果比較

⚠️ 限制

  • 過渡帶不如 Chebyshev / Elliptic 陡峭
  • 高階 IIR 濾波器有數值穩定問題，實作時要用二階節（SOS）
  • filtfilt 需要整段資料，無法即時處理
  • 頭尾邊界會有暫態，通常要捨棄或做 padding

在步態訊號中的應用

步態訊號的主要能量集中在 0～3 Hz（步頻與其諧波，demo 頻率響應圖中的陰影區），肌肉震顫與感測器雜訊多在 10 Hz 以上。因此 IMU 步態研究的標準前處理大多是：

4 階、零相位 Butterworth 低通，截止頻率 5～10 Hz，接著才做步態事件（heel strike、toe off）偵測與步態參數計算。

截止頻率不要憑感覺：可以先對訊號做 FFT 看能量分布，或用殘差分析（residual analysis）在不同 fc 之間做取捨。

Python 實作

import numpy as np
from scipy.signal import butter, sosfilt, sosfiltfilt

fs = 100          # 取樣頻率 (Hz)
cutoff = 5        # 截止頻率 (Hz)
order = 4         # 階數

# 用 SOS（二階節）格式，數值比 b, a 係數穩定
sos = butter(order, cutoff, btype="low", fs=fs, output="sos")

t = np.arange(0, 6, 1 / fs)
x = np.sin(2 * np.pi * 1.0 * t) + 0.25 * np.random.randn(t.size)

y_causal = sosfilt(sos, x)          # 單向：有延遲（即時系統）
y_zero = sosfiltfilt(sos, x)        # 雙向：零相位（離線分析）
