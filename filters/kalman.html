卡爾曼濾波Kalman Filter

每一步都在問：該相信「預測」還是相信「量測」？答案由兩者的不確定性決定。

原理

卡爾曼濾波不是在「平均」資料，而是在估計一個看不到的真實狀態。它反覆做兩件事：先用模型預測下一刻的狀態，再用新的量測修正預測。修正多少，取決於卡爾曼增益 K。

本頁示範最簡單的一維版本：假設真實值「大致不變，只會隨機慢慢漂移」（隨機漫步模型）。

模型： x[n] = x[n−1] + w, w ~ N(0, Q) ← 真實值每步會漂移多少 量測： z[n] = x[n] + v, v ~ N(0, R) ← 感測器有多吵 預測： x̂⁻ = x̂[n−1] P⁻ = P[n−1] + Q 增益： K = P⁻ / (P⁻ + R) 更新： x̂[n] = x̂⁻ + K · (z[n] − x̂⁻) P[n] = (1 − K) · P⁻

Q（過程雜訊）大 → 認為真實值變化快 → 更相信量測；R（量測雜訊）大 → 認為感測器很吵 → 更相信預測。真正影響結果的是 Q / R 的比值。

和 EMA 的關係

經過幾步之後 K 會收斂成定值，此時這個一維卡爾曼濾波完全等價於 α = K 的指數移動平均。卡爾曼濾波的威力在於多維狀態（例如同時估計角度與角速度）和融合多個感測器。

常見誤區：卡爾曼濾波不會自動變好。模型和 Q、R 設錯，結果可能比簡單的低通還差。在 demo 中觀察：Q/R 太小時，估計值會嚴重落後真實訊號。

參數怎麼調

參數意義調大會怎樣建議起始值
過程雜訊 Q模型每一步的不確定性反應更快、更貼近量測，平滑效果變弱從 R 的 1/10～1/100 開始試
量測雜訊 R感測器雜訊的變異數更平滑、更慢、延遲更大靜止錄一段資料，算變異數（σ²）直接當 R

demo 的滑桿是以 10 為底的對數刻度（log₁₀），因為 Q、R 常需要跨好幾個數量級調整。

優點與限制

👍 優點

  • 可以融合多個感測器（加速度計 + 陀螺儀 + 磁力計）
  • 能估計「量不到」的狀態，例如從加速度估速度
  • 同時給出估計值的不確定性 P，可以知道結果有多可靠
  • 遞迴計算，適合即時系統

⚠️ 限制

  • 需要系統模型；模型錯誤時結果會偏
  • Q、R 調參需要經驗，常被批評像「魔術數字」
  • 標準版只適用線性系統，姿態估計需用 EKF / UKF

在步態訊號中的應用

小腿 / 大腿傾角估計：陀螺儀積分會漂移、加速度計受衝擊影響很吵。卡爾曼濾波把兩者融合，狀態設為「角度 + 陀螺儀偏差」，即可得到穩定的關節角度曲線。

步長估計（足部 IMU）：腳掌著地時速度應為零，以此作為「虛擬量測」修正速度積分的漂移，即零速度更新（ZUPT, Zero-Velocity Update）。這是穿戴式步態分析估計步長的常見方法。

Python 實作

import numpy as np

def kalman_1d(z, Q=1e-2, R=1e-1):
    """一維隨機漫步模型的卡爾曼濾波，與本頁 demo 相同。"""
    z = np.asarray(z, dtype=float)
    x_hat = np.empty_like(z)
    est, P = z[0], 1.0
    for n, zn in enumerate(z):
        P = P + Q                      # 預測
        K = P / (P + R)                # 卡爾曼增益
        est = est + K * (zn - est)     # 更新
        P = (1 - K) * P
        x_hat[n] = est
    return x_hat

fs = 100
t = np.arange(0, 6, 1 / fs)
z = np.sin(2 * np.pi * 1.0 * t) + 0.25 * np.random.randn(t.size)
logQ, logR = -2, -1                    # 與 demo 滑桿相同的對數刻度
y = kalman_1d(z, Q=10**logQ, R=10**logR)

# 穩態增益（= 等價 EMA 的 alpha）
Q, R = 10**logQ, 10**logR
P_prior = (Q + np.sqrt(Q**2 + 4 * Q * R)) / 2
print("steady-state K =", P_prior / (P_prior + R))
