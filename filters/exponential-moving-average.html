指數移動平均Exponential Moving Average (EMA)

新輸出 = 一點點新資料 + 大部分舊輸出，只需要一個變數的記憶體。

原理

移動平均要記住最近 N 個點；EMA 只記住「上一次的輸出」，再把新進來的資料按比例混進去。越舊的資料，權重以指數速度衰減。

y[n] = α · x[n] + (1 − α) · y[n−1], 0 < α ≤ 1 展開後：y[n] = α·x[n] + α(1−α)·x[n−1] + α(1−α)²·x[n−2] + …

α（alpha）是平滑係數：α 越小，越相信過去、越平滑。它其實就是一個一階 IIR 低通濾波器，和電路課的 RC 低通是同一件事。

α 與時間常數的換算

時間常數 τ ≈ 1 / (α · fs) （α 很小時成立） 截止頻率 fc ≈ α · fs / (2π)

例如 fs = 100 Hz、α = 0.15 → τ ≈ 67 ms、fc ≈ 2.4 Hz。用這個關係就能從「想保留到幾 Hz」反推 α。

常見誤區：EMA 只能是因果的，所以一定有延遲，約為 (1−α)/α 個樣本。α = 0.15 時大約落後 57 ms。

參數怎麼調

參數意義調大會怎樣建議起始值
平滑係數 α新資料所佔的比例反應更快、延遲更小，但雜訊殘留更多先決定想要的 fc，再用 α ≈ 2π·fc / fs 換算；步態約 0.1～0.3

優點與限制

👍 優點

  • 每個樣本只要一次乘加，記憶體只需一個變數
  • 非常適合微控制器（Arduino、ESP32）上的即時處理
  • α 是連續值，可以細緻調整，不像視窗長度只能是整數

⚠️ 限制

  • 一階濾波器，截止頻率以外只以 −20 dB/decade 衰減，濾得不夠「乾淨」
  • 必定有相位延遲，且不同頻率延遲不同，波形會被扭曲
  • 對突波沒有抵抗力，一個大突波會拖出一條長尾巴

在步態訊號中的應用

穿戴式裝置在裝置端即時運算時最常用 EMA，例如鞋墊感測器即時估計步頻、或在藍牙傳輸前先把加速度做一次輕度平滑（α ≈ 0.3）。

如果資料是先錄起來再用電腦分析，通常會改用零相位的 Butterworth 濾波（見下一頁的比較），避免延遲影響步態事件的時間點。

Python 實作

import numpy as np
from scipy.signal import lfilter, lfilter_zi

def ema(x, alpha=0.15):
    x = np.asarray(x, dtype=float)
    b, a = [alpha], [1.0, -(1.0 - alpha)]   # y[n] = α x[n] + (1-α) y[n-1]
    zi = lfilter_zi(b, a) * x[0]             # 用第一個樣本當初值，與 demo 相同
    y, _ = lfilter(b, a, x, zi=zi)
    return y

fs = 100
fc = 2.4                                     # 想保留到約 2.4 Hz
alpha = 2 * np.pi * fc / fs                  # ≈ 0.15
t = np.arange(0, 6, 1 / fs)
x = np.sin(2 * np.pi * 1.0 * t) + 0.25 * np.random.randn(t.size)
y = ema(x, alpha)
